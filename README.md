# Nyora (にょら)

Nyora is a premium, state-of-the-art manga reader application for Android, featuring advanced page-at-once translation, real-time color correction, and highly intuitive navigation.

## Features

- **Page-at-Once AI Translation:** Leveraging high-context LLMs to cleanly translate and typeset manga dialogues in their natural page context.
- **Offline ML Kit Support:** High-speed on-device offline translation fallbacks.
- **Dynamic Color Correction:** Beautiful multi-tone filters for custom color balances.
- **Smooth Navigation:** Cached, preloaded, and beautifully transitions between chapters.
